Bench runs on real nappies with test fluid, recorded second by second. Compare products insult by insult instead of only cutting them open afterwards.

    Surface wetness after each insult

    How wet the sensor reads. Each insult is a spike. The faster it falls back, the faster the core pulls fluid away from the skin side.

    Humidity inside the nappy

    DHT11 placed inside the nappy. Humidity that stays high for longer means a damper microclimate against the skin.

    Side by side

    Measured from the same timed protocol for every product: dry baseline, equal insults a few minutes apart, then a press test.

    Can we trust the readings?

    The models are checked against labelled bench runs: we mark the exact moment fluid goes in, then see how quickly and how reliably the pod gets it right.

    Record a run

    Use the P&G nappies and saline at about body temperature. Put the moisture sensor in the same place for every product, and note where.
